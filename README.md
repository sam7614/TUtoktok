# 똑똑 · 수업 컨설팅 노트

동명대학교 찾아가는 교수법 똑-똑의 멘토 상담을 위한 개인용 앱입니다.

## 사용

1. 곽은주 또는 오소정 교수님을 선택합니다.
2. 수업고충상담, 1차 컨설팅, 2차 컨설팅 중 회차를 선택합니다.
3. 영역별 질문에 답변을 기록합니다. 모든 질문에 답할 필요는 없습니다.
4. 요약·저장에서 핵심 고민과 후속 합의를 정리합니다.
5. Google Docs로 저장 버튼을 누릅니다. 현재 회차의 전체 질문과 답변, 선택 후속 질문, 요약과 메모가 문서에 포함됩니다. 미작성 항목은 미작성으로 표시됩니다.

초안은 브라우저와 로그인한 계정에 자동 저장됩니다. 계정 저장 상태는 상단에서 확인할 수 있습니다. 백업/불러오기로 JSON 파일을 보관하고 복원할 수 있습니다. Google Docs 저장은 방문자의 연결 및 동의를 사용하며, 같은 내용의 재요청은 기존 문서를 반환합니다. 내용을 수정한 후 저장하면 별도 문서가 생성됩니다. 문서 생성/쓰기 결과가 불확실하면 자동 재시도하지 않고 안내합니다.

질문은 상담용 제안안입니다. 센터의 공식 보고서 양식이 아닙니다. 기본 교과목명은 작업 폴더의 수업계획서 파일명에서 가져왔으며 앱에서 수정할 수 있습니다.

## 개발

- Node 22.13 이상, Vinext / React / Cloudflare Workers / D1
- `npm run install:ci`, `npm run dev`, `npm run build`
- 호스팅 설정: `.openai/hosting.json`
- 저장 스키마 및 마이그레이션: `db/schema.ts`, `drizzle/`
- 연결 정보와 토큰은 플랫폼의 요청 범위 바인딩을 사용합니다. 소스에 자격 증명을 넣지 않습니다.

## Vercel 배포

루트의 `vercel.json`이 별도 Vite 클라이언트를 빌드합니다. Vercel 프로젝트의 Root Directory는 저장소 루트(`.`)로 두세요.

- Install Command: `npm --prefix vercel-app ci`
- Build Command: `npm --prefix vercel-app run build`
- Output Directory: `vercel-app/dist`
- Framework: Vite, Node.js 24

공통 UI와 질문은 빌드 시 `app/coach.tsx`, `app/globals.css`, `lib/questions.ts`에서 복사합니다. 생성된 복사본과 로컬 로그인 정보는 Git에 저장하지 않습니다.

Vercel 버전의 초안은 현재 브라우저에 보관됩니다. 기존 Sites 버전의 계정 기록과는 자동 동기화되지 않으므로, 이동할 때 백업/불러오기를 사용하세요. Google Docs 저장 버튼은 기존 본인 전용 Sites의 `/handoff` 창을 엽니다. 기록을 검토하고 저장을 누르면 기존의 Google 연결·동의·중복 방지 경로를 사용해 문서를 만듭니다. 문서 주소만 원래 창으로 돌아옵니다. Google 토큰이나 로그인 세션을 Vercel로 복사하지 않습니다.

기존 Sites 배포는 이 Google Docs 저장 연결에 계속 필요합니다. 브라우저 팝업을 허용해야 하며, 처음에는 ChatGPT/Google 연결 확인이 필요할 수 있습니다. 실제 Google 쓰기 검증과 로컬 통신 테스트는 구분합니다.

## 교수님별 4자리 잠금 (Vercel)

Vercel 첫 화면에서 교수님을 선택하고 해당 4자리 비밀번호를 입력합니다. 다른 교수님으로 전환하거나 새로 접속하면 다시 입력하며, 다시 잠그기 버튼과 15분 미사용 자동 잠금을 제공합니다.

`api/professor-access.mjs`가 서버에서 비밀번호를 확인합니다. 비밀번호와 세션 키는 Vercel의 Secret 환경변수 `PROFESSOR_PIN_0`, `PROFESSOR_PIN_1`, `PROFESSOR_SESSION_SECRET`에 저장하며 공개 코드나 브라우저 번들에 포함하지 않습니다. 세션 쿠키는 HttpOnly이며 교수님별 암호화 키 접근을 구분합니다. 연속 실패 시 브라우저 쿠키와 서버 인스턴스 기준으로 잠시 차단합니다.

브라우저 초안은 교수님별 AES-GCM 암호화 저장소를 사용합니다. 이전 평문 기록은 첫 입장 때 암호화 이관 후 평문 저장소를 제거합니다. 백업과 복원은 입장한 교수님의 기록만 다룹니다. 기존 비공개 Sites 버전은 멘토의 별도 계정 공간이며 Vercel 잠금과 구분됩니다.

`PROFESSOR_SESSION_SECRET`는 암호화 키의 기반이므로 변경하면 이전 브라우저 초안을 복호화할 수 없습니다. 변경 전 각 교수님의 기록을 백업해야 합니다. 이 키의 값은 저장소에 두지 않습니다.
